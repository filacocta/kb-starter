# kb synthesise

Resolve Personal from the installed config. Read _rules.md and
_workflows/synthesise.md, then only the target articles and relevant evidence.
The selected flow owns compilation, source dispositions and optional actions.
Do not load the ingestion/media/library contracts unless performing that work.

Improve mutable articles in place, including replacing redundant or obsolete
prose while preserving useful evidence and human annotations. Source records
stay unchanged. No mandatory global project scan, action inventory, page quota
or repeated phase approval. State material changes, evidence and unresolved limits.
