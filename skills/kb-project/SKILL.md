# kb project

Resolve the task's domain from the installed config. Context lookup uses
kb-query and writes nothing. Personal init/wrap uses _rules.md and
_workflows/project.md. That flow owns project structure and evidence lanes.
Consult schema/templates only for needed fields.

For topic-based creation, retrieve relevant topic context and existing projects
first. Current instructions authorize work; historical handoffs do not.
Use the prompt and repository for ordinary code facts. Link authoritative
boards/handoffs instead of creating redundant KB copies.

Team KBs use their repository's AGENTS.md, schema and existing context map.
Do not apply Personal ownership, feed or ingestion procedures to it.
