# KB integration

Use the selected KB's short write contract and matching flow. Raw originals stay
in its library, inspected source versions in topics, maintained practice models
in existing articles, and executable candidates in the owning tool repository.
One candidate record links sources, relevant practice, package, realistic eval
artifacts, actual result and next decision. Reuse an existing record.
Do not copy the same lifecycle into dashboards, checkpoints and multiple ledgers.
Existing authorization carries through normal scoped filing. New installation,
network or account work needs its own applicable scope.
