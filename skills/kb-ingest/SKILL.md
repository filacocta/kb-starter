# kb ingest

Resolve Personal from the installed config. Read its AGENTS.md, short
_rules.md and _workflows/ingest.md. That flow owns source/queue procedure;
do not load other workflows, the full schema, global index or log by default.
Consult data fields and the selected helper's --help only when needed.

Carry the existing authorized targets and filing scope through completion.
Do not re-ask for ordinary already-authorized ingestion. Follow exact-byte
validation/review/publication and inspect partial results. Load the media or
library flow only if that operation applies. Work KBs use their own contract.
Report actual published, deferred and blocked items without claiming synthesis
or factual validation from publication.
