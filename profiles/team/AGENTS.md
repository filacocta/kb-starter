# Team engineering KB

This repository maintains shared engineering guidance, decisions, runbooks and
dated evidence. Use prompt and code facts directly. Retrieve KB context only
when the task needs missing history, decisions or project orientation.
Read relevant sections from `knowledgebase/_context-map.md` and linked notes.
Lookup writes nothing and does not trigger maintenance or authorize operations.

For authorized edits, find the existing subject before adding a page. Preserve
human edits, authorship, useful history and disagreement. Improve the existing
narrative instead of copying it. Carry the authorized scope through without
repeated approval for ordinary steps. Use the team's branch and PR review process.
Canonical-copy decisions belong to the maintainer. Keep unresolved alternatives
labelled rather than choosing by edit date or deleting duplicates automatically.

Use SCHEMA.md for fields and evidence. Keep plans, inspected code, tests and
deployed observations distinct. A note or runbook is neither live evidence nor
execution authorization. Code and tools stay in their owning repositories;
link pinned revisions where practical. Keep account configuration and private
local handoffs out of the shared KB. No Personal ingestion contract applies here.
