# Library and skill promotion

Read the [write contract](../_rules.md). Keep one original binary in
`_library/books/` or `_library/docs/`; extracted source notes describe only the
inspected portions and are the topic citation surface. Custody is not ingestion.
Original binaries and extraction payloads need no YAML; control notes do.
Do not publish private/licensed originals with starter exports or Git mirrors.

The existing book ledger uses Wanted, Proposed, Acquired, Ingested. Mutate it
only through `kb-book-ledger.py`. Deduplicate title/author/year and preserve
references. Acquire only the specifically authorized legitimate copy, retaining
the canonical custody path and any relocation history. A proposed link is not
download authorization. Do not automatically acquire from shadow libraries.

Spent extraction dumps may be removed only under a concrete cleanup scope after
their useful content is incorporated, the retained binary can reproduce them,
and no further extraction or repair uses that dump. Preserve review-bound
evidence envelopes and the exact retained inputs still needed to reproduce
the reviewed observation; generating a new extraction is not the same evidence.
Update custody/disposition
records. A failed run or unchecked receipt is not proof an intermediate is spent.

Book-to-skill work requires an actual requested practice to automate, existing
skill/tool comparison, source-backed procedure and behavioral evaluation against
realistic cases. Prefer a deterministic helper when the operation is mechanical.
Keep candidates and eval fixtures separate from installed skills. Promotion is
a release decision under current user scope, not the automatic result of reading
a book or counting pages. Account switching and unrelated generic tooling are
outside this KB release.
