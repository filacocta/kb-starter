# Obsidian URI — Obsidian Help

**Type:** article

## Summary

The Obsidian URI protocol (`obsidian://`) provides a custom URL scheme for external automation, deep linking to notes, and inter-application communication. The basic format is `obsidian://action?param1=value&param2=value`. All parameter values must be URI-encoded, with forward slashes as `%2F` and spaces as `%20`.

Six core actions are supported: `open` (access a note or vault), `new` (create or append to a note), `daily` (open/create a daily note, requires Daily Notes plugin), `unique` (create a uniquely named note, requires plugin), `search` (launch search), and `choose-vault` (open vault manager). The `open` action supports targeting specific headings and blocks within a note using URL-encoded heading/block syntax.

Pane placement is configurable via `paneType`: default replaces the current tab; `tab` opens a new tab; `split` creates a tab group; `window` opens a desktop pop-out. Linux users must manually configure the protocol handler via an `obsidian.desktop` file.

## Key Points

- This is the protocol powering all `obsidian://` citations generated by KB skills [[notes/concepts/obsidian-uri-protocol]]
- URI encoding is mandatory: space → `%20`, `/` → `%2F`, `#` → `%23`, `^` → `%5E`
- `open` action with `file` param: `obsidian://open?vault=journal&file=path%2Fto%2Fnote`
- Heading navigation: append `%23Heading` to the file param
- Block navigation: append `%23%5EBlockID` to the file param
- `new` action supports `content` and `append` params — useful for programmatic note creation
- Linux WSL2 note: URI protocol must be configured manually; this KB runs on WSL2 so `obsidian://` links open on the Windows host (Obsidian is installed on Windows)
