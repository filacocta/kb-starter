## Summary

The Obsidian Help home page serves as the top-level navigation for the official documentation. It organises content into five getting-started steps (download, create vault, create notes, link notes, extend), an overview of the extension ecosystem (plugins, themes, CSS snippets), and references to premium services (Sync, Publish) and supplementary tooling including the Web Clipper browser extension and the official CLI.

## Key Points

- Getting started path: download → vault → notes → links → extend [[notes/concepts/obsidian-overview]]
- Thousands of community plugins and themes available; core plugins are built in [[notes/concepts/obsidian-plugins]]
- Web Clipper: browser extension for capturing web content directly into the vault
- CLI: terminal-based control tool referenced on this page [[notes/concepts/obsidian-cli]]
- Obsidian Sync (paid): cross-device sync; Obsidian Publish (paid): share vaults publicly
- Contributions accepted via GitHub; Catalyst and Commercial licenses available
