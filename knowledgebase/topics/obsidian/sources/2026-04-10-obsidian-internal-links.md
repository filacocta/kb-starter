# Internal Links — Obsidian Help

**Origin:** [Internal links — Obsidian Help](https://obsidian.md/help/Linking+notes+and+files/Internal+links)
**Ingested:** 2026-04-10
**Type:** article

## Summary

Obsidian supports two link formats for internal navigation: wikilinks (`[[Note name]]`) and Markdown links (`[Text](Note%20name)`). Wikilinks are the default due to their compactness; Markdown links can be enabled in Settings for interoperability with other tools. Both formats support custom display text — wikilinks use the pipe character (`[[Note|Display text]]`), Markdown links use the standard `[display](target)` syntax.

The internal link system supports three levels of targeting: whole-note links (`[[Note]]`), heading links (`[[Note#Heading]]`), and block links (`[[Note#^blockid]]`). Same-note heading links (`[[#Heading]]`) and block links (`[[#^blockid]]`) also work. Block identifiers can be auto-generated by Obsidian or manually specified using Latin characters, numbers, and dashes.

Obsidian automatically updates internal links when files are renamed (configurable). Characters that break links include `# | ^ : %% [[ ]]` — safe filename practices avoid these.

## Key Points

- Wikilinks are the canonical format in Obsidian; use them for all internal KB cross-references [[notes/concepts/obsidian-internal-links]]
- Heading links: `[[Note#Heading]]` — targets a specific section within a note
- Block links: `[[Note#^blockid]]` — targets a specific paragraph or block; Obsidian can suggest block IDs
- Custom display text: `[[Note|Display]]` — always prefer this over bare links for human readability
- Auto-rename tracking: renaming a file updates all wikilinks to it (unless disabled)
- Broken link characters: avoid `# | ^ : %% [[ ]]` in filenames
