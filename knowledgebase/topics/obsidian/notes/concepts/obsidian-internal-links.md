# Internal Links and Wikilinks

Internal linking is Obsidian's core distinguishing feature — the mechanism by which isolated notes become a connected knowledge graph. Two link formats exist; wikilinks are the default and are used throughout this KB.

## The Two Link Formats

**Wikilinks** (Obsidian default): `[[Note name]]`
- Compact, readable, Obsidian-native
- Auto-complete triggers with `[[`
- Obsidian tracks and updates these when files are renamed

**Markdown links**: `[Display text](Note%20name.md)`
- Portable to other Markdown tools
- Spaces must be URL-encoded as `%20`
- Can be enabled as the default in Settings > Files and links

Both formats support the same targeting features. This KB uses wikilinks for all internal cross-references.

## Targeting Within Notes

Three levels of targeting, all composable:

| Target | Wikilink syntax | What it opens |
|---|---|---|
| Whole note | `[[Note name]]` | The note from the top |
| Specific heading | `[[Note name#Heading]]` | The note scrolled to that heading |
| Specific block | `[[Note name#^blockid]]` | The note scrolled to that block |
| Same-note heading | `[[#Heading]]` | Current note, that heading |
| Same-note block | `[[#^blockid]]` | Current note, that block |

Block IDs are alphanumeric strings with hyphens (`my-block-1`). They can be auto-generated by Obsidian (random string) or manually written. To reference a block, place `^blockid` at the end of the paragraph you want to target.

## Embeds (Transclusion)

Prepend `!` to transclude rather than link:

- `![[Note name]]` — embed the entire note inline
- `![[Note name#Heading]]` — embed from that heading to the next
- `![[Note name#^blockid]]` — embed that specific block
- `![[image.png]]` — embed an image
- `![[file.pdf]]` — embed a PDF viewer inline
- `![[file.pdf#page=3]]` — embed a PDF opened to page 3

This makes transclusion a powerful tool for building composite documents from modular notes.

## Custom Display Text

Both formats support display text that differs from the target:

- Wikilink: `[[Note name|Display text]]`
- Markdown: `[Display text](Note%20name.md)`

Always use display text in this KB when the note slug is not human-readable, or when the context calls for a different phrasing.

## The Link Graph

Obsidian builds a real-time graph of all internal links. The Graph View (`Ctrl+G`) renders this as an interactive network. Key graph concepts:

- **Linked mentions** — notes linked explicitly with `[[]]`
- **Unlinked mentions** — notes whose names appear as plain text in other notes (Obsidian can detect these and suggest creating links)
- **Orphan notes** — notes with no inbound or outbound links; visible in graph as isolated nodes

The graph is also what makes `/kb-lint`-style analysis tractable: broken wikilinks and orphan notes are detectable by scanning the link structure.

## Important Constraints

Characters that break wikilinks and should be avoided in filenames: `# | ^ : %% [[ ]]`

Obsidian auto-updates links on rename by default — if this is disabled, manual link management becomes necessary.
