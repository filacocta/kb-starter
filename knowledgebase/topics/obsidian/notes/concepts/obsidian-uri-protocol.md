# The Obsidian URI Protocol

The `obsidian://` URI scheme is a custom protocol handler that allows external applications, scripts, and documents to trigger actions inside Obsidian — opening notes, creating content, launching searches — without Obsidian having to expose an API or run a server. It is the mechanism behind all citation deep-links generated by this KB's skills.

The basic format: `obsidian://action?parameter=value&parameter=value`

**URI encoding is mandatory.** All parameter values must be URL-encoded:
- Space → `%20`
- `/` → `%2F`
- `#` → `%23`
- `^` → `%5E`
- `|` → `%7C`

## Core Actions

### `open` — Open a note

```
obsidian://open?vault=journal&file=path%2Fto%2Fnote
```

Opens the specified note in the vault. Parameters:
- `vault` — vault name or UID
- `file` — path to the note file, URL-encoded, relative to vault root
- `path` — alternative to `file` (absolute path)

**Heading navigation:** append the heading to the `file` value: `file=note%23My%20Heading`
**Block navigation:** append block ID: `file=note%23%5EblockID`

**This is what this KB uses for all `obsidian://` citations:**
```
obsidian://open?vault=journal&file=knowledgebase%2Ftopics%2F<topic>%2Fnotes%2F<note>
```

### `new` — Create or append to a note

```
obsidian://new?vault=journal&file=path%2Fto%2Fnote&content=Hello
```

Parameters include `file`, `content`, `append` (append to existing rather than create), `overwrite`, `silent` (don't open the note after creation).

Useful for programmatic note creation from scripts or automation tools.

### `search` — Open search

```
obsidian://search?vault=journal&query=my+search+terms
```

Opens Obsidian with the Search panel active and the query pre-filled.

### `daily` — Open daily note

```
obsidian://daily?vault=journal
```

Opens or creates today's daily note (requires the Daily Notes core plugin to be enabled).

### `choose-vault` — Open vault manager

```
obsidian://choose-vault
```

Opens the vault selection screen.

## Pane Placement

The `open` and `new` actions support a `paneType` parameter:
- *(default)* — replaces the current tab
- `paneType=tab` — opens in a new tab
- `paneType=split` — opens in a split pane
- `paneType=window` — opens in a new window (desktop only)

## Platform Notes

**Windows/macOS:** URI protocol is registered automatically on Obsidian install.

**Linux (including WSL2):** Must manually create an `obsidian.desktop` file with `Exec=obsidian %u` to register the protocol. Since this KB runs on WSL2 but Obsidian is installed on the Windows host, `obsidian://` links opened from within WSL terminal sessions will invoke the Windows Obsidian application correctly via the Windows URI handler.

## Generating KB Citation Links

Template for generating a citation link to any note in this KB:

```
obsidian://open?vault=journal&file=knowledgebase%2Ftopics%2F<topic>%2Fnotes%2F<type>%2F<slug>
```

Example — linking to this note:
```
obsidian://open?vault=journal&file=knowledgebase%2Ftopics%2Fobsidian%2Fnotes%2Fconcepts%2Fobsidian-uri-protocol
```
