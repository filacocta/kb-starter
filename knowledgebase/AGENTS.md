# Personal KB

This KB maintains source-based topic articles and personal project continuity.
Team engineering KBs have their own contract; see the optional team profile.

For context, use kb-query or bounded filesystem retrieval. Read the relevant
summary, article and evidence. Use the prompt and repository for facts already
available there. Lookup does not load write contracts or perform maintenance.

For writes, read [_rules.md](_rules.md) and the one matching flow:

- [Ingest](_workflows/ingest.md) for source publication and queue completion.
- [Synthesise](_workflows/synthesise.md) for maintained topic articles.
- [Project](_workflows/project.md) for project init, context and wrap.
- [Maintenance](_workflows/maintenance.md) for triage, lint, corrections and cleanup.
- [Media](_workflows/media.md) only for media capture or inspection.
- [Library](_workflows/library.md) only for books, custody or skill promotion.

[_schema.md](_schema.md) describes formats. [_tools/README.md](_tools/README.md)
locates executable operations. No other rule list is required.
Existing source paths and the containing Personal Obsidian vault remain in place.
